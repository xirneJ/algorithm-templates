## 易错点

- 进制 P 取 131 或 13331，用 unsigned long long 自然溢出即可。
- 子串哈希：h[r] - h[l-1] * P^(r-l+1)，下标从 1 开始。
- 担心被卡可以换随机 base，或者用双哈希。
