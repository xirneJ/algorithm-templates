# AcWing 801. 二进制中1的个数

## 模板

```cpp
#include <stdio.h>
#include <stdlib.h>
int main()
{
    int n=0;
    scanf("%d",&n);
    while(n--)
    {
        int num=0;
        scanf("%d",&num);
        int count=0;
        while(num)
        {
            if(num&1)
            {
                count++;
            }
            num>>=1;
        }
        printf("%d ",count);
    }
    return 0;
}
```
