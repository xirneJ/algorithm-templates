# AcWing 891. Nim游戏

## 模板

```cpp
#include <stdio.h>
#include <stdlib.h>
int main()
{
    int n=0;
    int res=0;
    scanf("%d",&n);
    while(n--)
    {
        int m=0;
        scanf("%d",&m);
        res=res^m;
    }
    if(res==0)
    {
        printf("No\n");
    }
    else
    {
        printf("Yes\n");
    }
    return 0;
}
```
