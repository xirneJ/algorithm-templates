# AcWing 892. 台阶-Nim游戏

## 模板

```cpp
#include <stdio.h>
int main()
{
    int n=0;
    int i=0;
    int num=0;
    int res=0;
    scanf("%d",&n);
    for(i=1;i<=n;i++)
    {
        scanf("%d",&num);
        if(i%2==1)
        {
            res=res^num;
        }
    }
    if(res==0)
    {
        printf("No\n");
    }
    else
    {
        printf("Yes\n");
    }
    return 0;
}
```
