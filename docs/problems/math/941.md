# AcWing 872. 最大公约数

## 模板

```cpp
#include <stdio.h>
#include <stdlib.h>
int gcd(int a,int b)
{
    return b?gcd(b,a%b):a;
}
int main()
{
    int n=0;
    scanf("%d",&n);
    int i=0;
    int a=0;
    int b=0;
    int res=0;
    for(i=0;i<n;i++)
    {
        scanf("%d %d",&a,&b);
        res=gcd(a,b);
        printf("%d\n",res);
    }
    return 0;
}
```
