# AcWing 873. 欧拉函数

## 模板

```cpp
#include <stdio.h>
#include <stdlib.h>
int main()
{
    int n=0;
    scanf("%d",&n);
    int num=0;
    while(n--)
    {
        scanf("%d",&num);
        int res=num;
        int i=0;
        for(i=2;i<=num/i;i++)
        {
            if(num%i==0)
            {
                res=res/i*(i-1);
            }
            while(num%i==0)
            {
                num/=i;
            }
        }
        if(num>1)
        {
            res=res/num*(num-1);
        }
        printf("%d\n",res);
    }
    return 0;
}
```
