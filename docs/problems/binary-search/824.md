# AcWing 790. 数的三次方根

## 模板

```cpp
#include <iostream>
using namespace std;
int main()
{
    double x=0;
    cin>>x;
    double l=-10000;
    double r=10000;
    while(r-l>1e-8)
    {
        double mid=(r-l)/2+l;
        if(mid*mid*mid>=x)
        {
            r=mid;
        }
        else
        {
            l=mid;
        }
    }
    printf("%lf",l);
    return 0;
}
```
