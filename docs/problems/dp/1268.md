# AcWing 1024. 装箱问题

## 模板

```cpp
#include <algorithm>
#include <iostream>
using namespace std;
int arr[35];
int dp[20010];
int main()
{
    int V,n;
    cin>>V>>n;
    int i,j;
    for(i=0;i<n;i++)
    {
        cin>>arr[i];
    }
    for(i=0;i<n;i++)
    {
        for(j=V;j>=arr[i];j--)
        {
            dp[j]=max(dp[j],dp[j-arr[i]]+arr[i]);
        }
    }
    cout<<V-dp[V]<<endl;
    return 0;
}
```
