# AcWing 1023. 买书

## 模板

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int arr[5]={10,20,50,100};
int dp[1010];
int main()
{
    int m;
    cin>>m;
    int i,j;
    dp[0]=1;
    for(i=0;i<4;i++)
    {
        for(j=arr[i];j<=m;j++)
        {
            dp[j]+=dp[j-arr[i]];
        }
    }
    cout<<dp[m]<<endl;
    return 0;
}
```
