# AcWing 278. 数字组合

## 模板

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int dp[10010];
int main()
{
    int n,m;
    cin>>n>>m;
    int i,j;
    int arr[110]={0};
    for(i=0;i<n;i++)
    {
        cin>>arr[i];
    }
    dp[0]=1;
    for(i=0;i<n;i++)
    {
        for(j=m;j>=arr[i];j--)
        {
            dp[j]+=dp[j-arr[i]];
        }
    }
    cout<<dp[m]<<endl;;
    return 0;
}
```
