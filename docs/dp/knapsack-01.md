# 01 背包

## 思路

该模板覆盖「背包、01背包、DP」相关问题。下面的代码保留竞赛中常用的实现结构；遇到具体题目时，需要根据数据范围调整数组大小、边界和取模方式。

**相关标签：** 背包、01背包、DP


## 复杂度

| 时间 | 空间 |
| --- | --- |
| `O(nm)` | `O(m)` |

## 易错点

- 倒序遍历保证 dp[j - v[i]] 还是「上一层」的状态。
- 如果要求恰好装满，dp[0] = 0、其余初始化为 -INF。
- 统计方案数时把 max 换成求和。
