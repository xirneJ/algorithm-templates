# 算法模板库 OI Wiki 风格重构设计

**日期：** 2026-10-20  
**状态：** 已确认，进入实现  
**目标：** 将现有手写单页算法模板库重构为接近 OI Wiki 动态规划页面的静态文档站，同时保留 32 个算法模板。

## 1. 技术栈

- MkDocs 1.6.1
- Material for MkDocs 9.6.15
- Python 3.12
- Markdown、Material 内置搜索、Pygments 代码高亮
- 自定义 `extra.css`，不引入前端框架

选择原因：OI Wiki 当前页面由 MkDocs Material 9.6.15 生成。使用同一主题和相近配置可以自然获得 48px 顶栏、49px 分类标签栏、三栏布局、左侧 12.1rem 导航、右侧 12.1rem 页内目录、61rem 内容网格以及 Fira Sans / Fira Mono 字体体系。

## 2. 信息架构

顶级导航标签固定为：

1. 基础算法
2. 数据结构
3. 图论
4. 动态规划
5. 数学
6. 字符串

每个分类包含一个索引页与现有算法页面。共 32 个算法页面：

- 基础算法 5
- 数据结构 5
- 图论 8
- 动态规划 5
- 数学 5
- 字符串 4

首页提供简短介绍、六个分类入口和使用说明。

## 3. 页面模板

每个算法页统一结构：

```markdown
# 算法名称

一句话摘要。

## 思路

说明与要点。

## 模板

```cpp
// 可直接复制的 C++ 模板
```

## 复杂度

| 时间 | 空间 |
| --- | --- |
| O(...) | O(...) |

## 易错点

- ...
```

页面 frontmatter 保存 `title`、`description` 与标签，便于搜索结果与 SEO。

## 4. 视觉规范

- 主色：`#4051b5`
- 强调色：`#526cfe`
- 正文：`rgba(0, 0, 0, .87)`
- 次级文字：`rgba(0, 0, 0, .54)`
- 代码背景：`#f5f5f5`
- 代码文字：`#36464e`
- 正文字体：Fira Sans
- 代码字体：Fira Mono
- 正文基准字号：16px，行高 1.6
- 三栏网格最大宽度：61rem（Material 根字号 20px 时为 1220px）
- 左右侧栏各 12.1rem
- 顶栏与标签栏保持 Material 默认尺寸和留白
- 默认浅色主题；深色主题沿用 Material slate，并采用 OI Wiki 的 `#2e303e` / `#00bda4` 强调色
- 代码块启用复制按钮；表格与提示块沿用 Material 默认样式

## 5. 内容迁移

从现有 `js/algorithms.js` 一次性读取 32 条数据，生成 Markdown 页面。迁移后站点运行不依赖旧 JavaScript、旧 HTML 或旧 CSS。旧文件在验证完成前保留，避免不可逆删除。

## 6. 测试与验收

- `node tests/site.test.mjs`：验证 32 个页面、统一结构、主题配置、颜色变量和构建产物 DOM。
- `mkdocs build --strict`：构建必须无警告、无断链。
- 浏览器检查：桌面端三栏布局、右侧目录、分类标签、搜索框、代码复制按钮和移动端抽屉。
- 参考站关键几何：顶栏 48px、标签栏 49px、左右侧栏 242px、正文内容 688px（1267px 视口、参考站同配置下）。

## 7. 非目标

- 不复制 OI Wiki 的正文内容。
- 不实现评论、贡献者列表、GitHub 仓库星标。
- 不引入登录、后台、数据库或运行时 API。
